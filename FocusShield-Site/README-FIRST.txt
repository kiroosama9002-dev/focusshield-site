1. Put your two files in this folder (next to index.html), with these exact names:
   FocusShield.apk
   FocusShield-Extension.zip
2. Upload everything in this folder to a PUBLIC GitHub repo, then Settings -> Pages -> Deploy from branch main / root.
3. Windows ZIP is too big for the website: create a Release (Releases -> Create a new release), attach it named
   FocusShield-Windows-x64.zip, and click Publish.
